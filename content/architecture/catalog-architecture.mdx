---

Most platforms treat the catalog as a **database**.

Rows.  
Fields.  
Metadata.  
Filters.

This is the legacy model — a static list of products with tags attached. It works for stores. It does not work for **platforms**.

A platform needs a catalog that understands:

- **structure**  
- **relationships**  
- **identity**  
- **continuity**  
- **taxonomy**  
- **taste**  
- **play patterns**  
- **studio identity**  
- **IP architecture**  

A database can’t do that.  
A catalog can.

The catalog is not a list.  
The catalog is a **world model**.

# THE CATALOG AS A WORLD MODEL

The catalog must understand:

### 1. IP Worlds  
Halo, Fallout, Forza, Minecraft — each is a universe with internal logic.

### 2. Series Lineage  
Mainline → spin-off → reboot → remaster → live service.

### 3. Studio Identity  
Arkane ≠ id Software ≠ Playground ≠ Ninja Theory.

### 4. Experience Taxonomy  
Short-loop, mid-loop, long-loop.  
Combat, creation, exploration, sociality.

### 5. Taste Graph Signals  
Tone, intensity, mastery, identity.

### 6. Continuity  
What came before.  
What comes next.  
What belongs together.

This is how a platform becomes **coherent**.
